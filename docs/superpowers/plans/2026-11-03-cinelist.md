# CineList Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** App .NET MAUI de películas (CRUD en Firestore) cuyo núcleo es un `ListView` con una clase `PeliculaViewCell`, evento `ItemTapped`, modo claro/oscuro y animaciones, para la Guía 8.

**Architecture:** Lógica pura (modelo, mapeo Firestore, filtros, validación, políticas de póster, repositorio REST) en una librería `net9.0` testeable con xUnit. La app MAUI (`net9.0-android`) consume esa librería y solo contiene UI: páginas XAML, ViewModels con CommunityToolkit.Mvvm, la `ViewCell`, tema y animaciones.

**Tech Stack:** .NET 9, .NET MAUI 9, CommunityToolkit.Mvvm 8.4.0, System.Text.Json, xUnit, Firestore REST v1.

**Spec:** `docs/superpowers/specs/2026-11-03-cinelist-design.md`

## Global Constraints

- Target: `net9.0-android` (iOS/Windows TFMs condicionales como en TiendaApp, no se compilan en Linux). `SupportedOSPlatformVersion` Android 21.
- Paquete Android: `com.cinelist.app`. Título visible: `CineList`.
- Firestore: proyecto `cinelist-7a4de`, colección `movies`, API key `AIzaSyBkCaRxSZDMS0uvn2IvqDWyjUDnhruJckE`, base `https://firestore.googleapis.com/v1/projects/cinelist-7a4de/databases/(default)/documents`, `?key=` en cada request.
- Campos Firestore exactos: `title, director, genre, year, durationMin, synopsis, watched, rating, poster, createdAt`.
- Lista DEBE ser `ListView` con `ItemTemplate` = `DataTemplate(typeof(PeliculaViewCell))`; `PeliculaViewCell : ViewCell` en C#. Nunca `CollectionView`.
- Evento de selección: `ItemTapped` manejado en `PeliculasPage.xaml.cs`.
- Póster: lado mayor 600 px, JPEG calidad 70, objetivo ≤ 300 000 bytes, máximo 900 000 bytes de base64.
- Colores: exactamente los de la tabla "Diseño visual" del spec, como `AppThemeBinding` (oscuro/claro).
- Animaciones: 150–350 ms, `Easing.CubicOut`; ver lista del spec. Saltar las decorativas si el sistema pide reducir movimiento.
- Sin emojis; íconos vectoriales (fuente Material Symbols).
- Textos de UI en español.
- Build Android: `dotnet build src/CineList -f net9.0-android -p:JavaSdkDirectory=/usr/lib/jvm/java-17-openjdk -p:AndroidSdkDirectory=$HOME/Android/Sdk`.
- Emulador: `$HOME/Android/Sdk/emulator/emulator -avd Pixel_8`. No usar `pm clear` en Debug; desinstalar y reinstalar.

## Review Focus

1. **Sin internet / Firestore caído:** la lista muestra estado de error con "Reintentar", nunca crashea; guardar muestra mensaje y conserva el formulario. → test en Task 4 (`ListarAsync` con handler que lanza `HttpRequestException` → `RepositorioException.SinConexion == true`).
2. **Foto enorme de cámara (12 MP):** se reduce y queda ≤ 900 000 bytes base64; si no cabe, mensaje claro. → tests en Task 3 (`Escalar(4000,3000)` → `(600,450)`; `CabeEnDocumento`).
3. **Búsqueda con tildes y mayúsculas:** "interestelar", "INTERESTELAR", "chihiro", "miyazaki", "pelicula" encuentran "Película". → tests en Task 2.
4. **Formulario inválido:** título solo espacios, año "abc" o 1500, duración 0 o negativa → errores, no se guarda. → tests en Task 3 (`ValidadorPelicula`).
5. **Documento incompleto en Firestore** (creado luego desde la web, campos faltantes, `year` como `integerValue` string, género vacío): se mapea con valores por defecto y cae en grupo "Sin género". → tests en Task 1 y Task 2.
